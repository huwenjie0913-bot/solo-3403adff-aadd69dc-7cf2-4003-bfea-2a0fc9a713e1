# 天线匹配网络设计器 (Antenna Matching Network Designer)

供业余无线电制作者设计天线匹配网络的本地 Web 应用。Flask + SQLite 后端，
NumPy/SciPy 负责复阻抗计算与候选搜索；浏览器端为原生 HTML/CSS/JavaScript + SVG。

## 运行

```bash
pip install flask numpy scipy
python3 app.py
# 浏览器打开 http://127.0.0.1:5000
```

## 使用流程

1. **导入数据**：粘贴 `频率, R, X` 的 CSV（MHz 自动识别；也支持单列复阻抗
   如 `42.3-18.7j`），或点「载入示例」。
2. **填写系统参数**：系统阻抗 Z0、馈线特性阻抗 / 长度 / 速度因子 / 损耗、
   发射功率、目标频段。
3. **选择结构与限制**：L / Π / T / 短截线拓扑族；L、C、线段取值上下限，
   耐压 / 耐流、元件 Q、目标驻波。
4. **搜索候选**：应用在中心频率精确匹配，并在整个目标频段评分。
5. **交互分析**：
   - Smith 圆图同时绘制 **负载 / 馈线变换 / 匹配后** 三条轨迹；
   - 拖动电路原理图上的黄色手柄（或在元件上滚轮）改变 L/C/短截线，
     驻波、回损、元件电压/电流/耗散、估算损耗实时更新；
   - 响应图在 SWR / RL / 总损耗间切换，移动鼠标即定位频点。
6. **问题标记**：窄带尖峰、元件越额、参数触边、高 Q、近似多解；
   点击标签/问题项直接跳到对应频点。
7. **版本与导出**：保存方案到 SQLite、比较带宽与元件值；
   导出电路 SVG、物料表 (BOM CSV) 和逐频点 JSON。

## 文件结构

| 文件 | 作用 |
|---|---|
| `app.py` | Flask 路由：CSV 解析、馈线变换、搜索、版本存取 |
| `rf.py` | 复阻抗/传输线原语、全网络评估（SWR、RL、损耗、元件应力） |
| `search.py` | 拓扑目录（4 L 型 × 摆位、8 Π、8 T、单短截线）、L 型闭式解、SciPy 最小二乘求解、评分与标记 |
| `db.py` | SQLite 版本持久化 |
| `test_rf.py` | 复阻抗与网络评估回归测试 |
| `static/` | 前端：Smith 圆图、原理图、响应图（SVG）与状态逻辑 |

## 约定与模型

- 时间因子 e^{jωt}：电感 +jωL，电容 1/(jωC)。
- 元件 Q 用串联电阻模型（L: R=X/Q，C: R=|X|/Q），并联元件换算为等效并联电阻。
- 源用 RMS 戴维南等效：可用功率 P 对应 Vth=2√(P·Z0)。
- 总损耗 = 失配损耗 + 元件耗散损耗；线段损耗按 dB/100 m、√f 趋肤折算。
- 线段电长度 θ=βℓ 在中心频率定义；候选在中心精确匹配（|Γ| 验收），
  再在含 f0 的 400 点密集网格上评估整个频段。

## 测试

```bash
python3 -m unittest test_rf -v
```

覆盖：电容/电感 ESR 与电抗虚部、归一化电抗、L 型两种摆位的精确匹配、
谐振槽路 SWR=1、电容电压电流应力等。
